# Rang-o-Riwaaj

Next.js storefront for a Pakistani fashion house. Shoppers browse collections, compare pieces, and go through cart and checkout. Staff manage the catalog from an admin desk.

## Stack

Next.js, React, TypeScript, Tailwind CSS

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

Admin sign-in is at `/admin/login`. Copy `.env.example` to `.env` and set `ADMIN_PASSWORD`. Leave it empty to keep the desk locked.
